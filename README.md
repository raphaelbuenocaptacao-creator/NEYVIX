# NEYVIX

NEYVIX is a global digital ecosystem built around one identity and a connected family of products.

## Vision
**One identity. Your digital world.**

NEYVIX starts with identity and communication, then expands into social, AI, productivity, payments and cloud services.

## Phase 1 — Foundation
- **NEYVIX ID** — universal account, authentication, sessions and account security
- **NEYVIX Mail** — modern email experience
- **NEYVIX Admin** — operations, security, audit and platform metrics

## Phase 2 — Communication & Intelligence
- **NEYVIX Chat** — private messaging, groups, voice and video
- **NEYVIX AI** — intelligence layer across the ecosystem
- **NEYVIX Meet** — meetings and calls

## Phase 3 — Digital Ecosystem
- **NEYVIX Social** — social network
- **NEYVIX Drive** — files and storage
- **NEYVIX Docs** — documents and collaboration
- **NEYVIX Business** — tools for companies

## Phase 4 — Financial & Infrastructure
- **NEYVIX Pay** — payments and wallet, using compliant regulated infrastructure
- **NEYVIX Cloud** — developer and infrastructure services
- **NEYVIX Financial Services** — future regulated financial products through the appropriate licensed structure/partners

## Product principles
1. One NEYVIX ID across every product.
2. Security and privacy by design.
3. Mobile-first and simple enough for anyone to use.
4. Shared design system and shared platform services.
5. Products launch independently but work better together.
6. Financial services are only launched with the required regulatory structure.

## Initial architecture
- Next.js + React + TypeScript
- PostgreSQL / Neon
- Vercel
- API-first service boundaries
- Shared identity, security, audit and notification layers

## Current priority
1. NEYVIX ID
2. NEYVIX Mail
3. NEYVIX Admin
4. Mail delivery/receiving infrastructure
5. Closed beta
