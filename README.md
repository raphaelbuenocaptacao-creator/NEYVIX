# ZYVO

ZYVO is a global productivity ecosystem starting with **ZYVO ID** and **ZYVO Mail**.

## Vision
One account. Everything connected.

## Initial products
- ZYVO ID — identity, authentication and account security
- ZYVO Mail — modern email experience
- ZYVO AI — intelligent assistance layer
- ZYVO Admin — operations, security, audit and metrics

## Planned ecosystem
- ZYVO Drive
- ZYVO Calendar
- ZYVO Meet
- ZYVO Docs
- ZYVO Business
- ZYVO Cloud
- ZYVO Pay

## Initial stack
- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL / Neon
- Vercel

## Status
Project bootstrap in progress.
